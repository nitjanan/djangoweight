# คิดค่าน้ำมันรายเที่ยว (per-trip fuel price)

วันที่ 2026-09-04 · branch `excel_สรปรายงานรถสงออก`

## ปัญหา

ราคาน้ำมันเปลี่ยนจากกรอกเดือนละครั้ง มาเป็นกรอกรายวันใน `InternationalFreightRateFuelPrice`
แต่ไฟล์ Excel ยังคิดเงินแบบ "อัตราเดียวต่อกลุ่ม" อยู่

เส้นทางเงินในไฟล์ปัจจุบัน

```
บันทึกรายเที่ยว          อัตราค่าขนส่ง                สรุปจ่ายรถร่วม
M = ตันของเที่ยว          G = ค่าขนส่งตามสัญญา          AS = Σ ตันของกลุ่ม
V = คีย์ 5 ช่อง           K = (I−H)×J                  BD = อัตราสุทธิของกลุ่ม
                        L = G+K                      AU = AS × BD   ← เงิน
```

`AU = AS × BD` คูณทีเดียวทั้งกลุ่ม — ตันทั้งเดือนคูณอัตราตัวเดียว
ตราบใดที่ยังคูณตรงนี้ ราคาน้ำมันต้องยุบเหลือตัวเลขเดียวต่อกลุ่มเสมอ
ไม่มีที่ให้ราคารายวันแทรกเข้าไปได้

## สูตรที่ต้องการ

```
ส่วนปรับน้ำมัน (บาท/ตัน) = (ราคาน้ำมันวันที่วิ่ง − ราคาน้ำมันฐาน) × อัตราการปรับ
อัตราสุทธิของเที่ยว       = ค่าขนส่งตามสัญญา + ส่วนปรับน้ำมัน
เงินของเที่ยว            = นน.จ่ายค่าบรรทุก × อัตราสุทธิของเที่ยว
```

แหล่งข้อมูล

| ค่า | มาจาก |
|---|---|
| ราคาน้ำมันฐาน (H) | `InternationalFreightRate.base_fuel_price` |
| อัตราการปรับ (J) | `InternationalFreightRate.fuel_freight_adjustment` |
| ค่าขนส่งตามสัญญา (G) | `InternationalFreightRateTeam.freight_rate` — ขึ้นกับทีม |
| ราคาน้ำมันวันที่วิ่ง | `InternationalFreightRateFuelPrice` (บริษัท × วันที่) |

บริษัทของเที่ยวหนึ่งมาจาก `origin.base_company_id`
โดย `origin` เป็นแถวใน `BaseCompanyMapBaseCustomer`

## ทางเลือกที่พิจารณา

**1. ย้ายจุดคูณไปที่แถวรายเที่ยว** ← เลือกอันนี้
หน้าสรุปเปลี่ยนจาก "คูณ" เป็น "บวก" แก้สูตร 3 ช่อง ที่เหลือเป็นคอลัมน์ช่วยที่ซ่อนอยู่แล้ว

**2. แตกแถวอัตราโดยเพิ่มวันที่เข้าไปในคีย์**
ไม่ต้องแก้สูตรเลย แต่ 71 กลุ่ม × วันที่วิ่ง = หลายร้อยแถว
หน้าสรุปจ่ายรถร่วมจะแตกเป็นบรรทัดละวัน อ่านไม่ออก และช่องเก็บมีแค่ 400 บล็อก

**3. ให้ Django คำนวณแล้วเขียนอัตราสุทธิลงช่อง L เป็นค่าคงที่**
ง่ายสุด ตัวเลขตรง แต่บัญชีแก้ราคาในไฟล์แล้วเลขไม่ขยับ
ขัดกับที่ template เขียนไว้เองว่า "แก้ทับช่องเดิมได้เลย หน้าสรุปจะคิดใหม่ให้ทันที"

## การตัดสินใจที่ตกลงกันแล้ว

| หัวข้อ | ผล |
|---|---|
| เครื่องหมายในสูตรส่วนปรับ | **ลบ** — `(รายวัน − ฐาน) × ปรับ` ตามที่มีใน template ไม่แก้สูตร K |
| วันที่ยังไม่ได้กรอกราคา | **ใช้ราคาวันล่าสุดก่อนหน้าที่มี** (carry forward) พร้อมทำเครื่องหมายให้เห็น |
| Sheet ใหม่ + สูตรที่แก้ | **สร้างตอน export** ไม่ฝังลง template ที่เก็บใน repo |

เหตุผลข้อสุดท้าย: ไฟล์ `trip_report_template_v11.xlsx` ใน repo ต้องเหมือนของฝ่ายบัญชีเป๊ะ
วันหน้าเขาส่ง v12 มาจะได้วางทับได้เลย เป็นแนวเดียวกับ `_exportDocumentHoistNoTeam` ที่ทำอยู่แล้ว

# แบบ

## 1. Sheet ใหม่ "น้ำมันรายวัน"

แถว = เหมืองต้นทาง · คอลัมน์ = วันที่ 1–31 · เห็นทั้งเดือนในจอเดียว

```
     A                B      C      D      E    ...   AF
 1   ราคาน้ำมันรายวัน (บาท/ลิตร)
 2   ระบบเติมให้จากที่กรอกในเว็บ | แก้ทับได้ หน้าสรุปคิดใหม่ทันที
 3   ช่องสีเทา = วันนั้นยังไม่ได้กรอกราคา ระบบใช้ราคาวันก่อนหน้าแทน
 4   เหมืองต้นทาง      1      2      3      4    ...   31
 5   กงตาก1         31.50  31.50  31.75  31.75  ...  32.10
 6   กงตาก3         31.50  31.50  31.75  31.75  ...  32.10
 7   ควนเนียง       30.90  30.90  31.05  ▓▓▓▓▓  ...  31.40
```

- ขนาด: แถว 5–54 (50 เหมือง) · คอลัมน์ B–AF (31 วัน)
- แถวเป็น "เหมืองต้นทาง" ไม่ใช่ "บริษัท" เพราะในไฟล์ไม่มี concept บริษัท
  แถวรายเที่ยวมีแต่ชื่อเหมือง เหมืองที่อยู่บริษัทเดียวกันจะได้เลขซ้ำกัน
  ซึ่งถูกต้อง และอ่านง่ายกว่าให้บัญชีต้องรู้ว่าเหมืองไหนสังกัดบริษัทไหน
- ใส่เฉพาะเหมืองที่วิ่งจริงในเดือนนั้น
- ชื่อเหมืองต้องเป็นข้อความเดียวกับคอลัมน์ B ของบันทึกรายเที่ยวเป๊ะ (ไฟล์ผูกกันด้วยข้อความ)
- freeze pane ที่ B5 · number format `0.00`

## 2. บันทึกรายเที่ยว — คอลัมน์ช่วยใหม่ AB–AH

คอลัมน์ช่วยเดิมใช้ถึง AA ตั้งแต่ AB ว่าง
เขียนสูตรถึงแถวสุดท้ายที่มีข้อมูล + 50 แถว ไม่ต้องเขียนครบ 3005 แถวให้ไฟล์บวม

| ช่อง | คือ | สูตร (แถว 6) |
|---|---|---|
| AB | ราคาน้ำมันวันนั้น | `=IF($A6="","",IFERROR(INDEX(น้ำมันรายวัน!$B$5:$AF$54,MATCH($B6,น้ำมันรายวัน!$A$5:$A$54,0),DAY($A6)),""))` |
| AC | ค่าขนส่งตามสัญญา G | `=IF($V6="","",IFERROR(INDEX(อัตราค่าขนส่ง!$G$5:$G$204,MATCH($V6,อัตราค่าขนส่ง!$M$5:$M$204,0)),""))` |
| AD | ราคาน้ำมันฐาน H | เหมือน AC แต่ช่วง `$H$5:$H$204` |
| AE | อัตราการปรับ J | เหมือน AC แต่ช่วง `$J$5:$J$204` |
| AF | ส่วนปรับน้ำมัน | `=IF(OR($AB6="",$AD6="",$AE6=""),0,ROUND(($AB6-$AD6)*$AE6,2))` |
| AG | อัตราสุทธิของเที่ยวนี้ | `=IF($AC6="","",ROUND(N($AC6)+N($AF6),2))` |
| AH | เงินของเที่ยวนี้ | `=IF(OR($AG6="",$M6=""),0,ROUND($M6*$AG6,2))` |

`A6` เป็นวันที่จริง (`datetime.date`) ไม่ใช่ข้อความ `DAY()` จึงใช้ได้
`V6` คือคีย์ 5 ช่องเดิม `ทีม|ต้นทาง - ปลายทาง(แบก นน.)|ชนิดหิน`

เที่ยวที่หาสัญญาไม่เจอ AC = `""` → AG = `""` → AH = 0
ตรงกับพฤติกรรมเดิมที่ `IFERROR(...,0)` ทำให้อัตราเป็น 0 แล้วเงินเป็น 0

## 3. สรุปจ่ายรถร่วม — แก้สูตร 3 ช่อง (แถว 5–404)

| ช่อง | เดิม | ใหม่ |
|---|---|---|
| AU | `=ROUND($AS5*$BD5,2)` | `=IF($Y5="",0,ROUND(SUMIF(บันทึกรายเที่ยว!$V$6:$V$3005,$Y5,บันทึกรายเที่ยว!$AH$6:$AH$3005),2))` |
| BD | `=IF($Y5="",0,IFERROR(INDEX(อัตราค่าขนส่ง!$L$5:$L$204,MATCH($Y5,อัตราค่าขนส่ง!$M$5:$M$204,0)),0))` | `=IF(N($AS5)=0,0,ROUND($AU5/$AS5,2))` |
| BC | `=IF($Y5="",0,IFERROR(INDEX(อัตราค่าขนส่ง!$K$5:$K$204,MATCH($Y5,อัตราค่าขนส่ง!$M$5:$M$204,0)),0))` | `=ROUND(N($BD5)-N($AT5),2)` |

ไม่เกิด circular reference: `AU` อ่านจาก sheet รายเที่ยว → `BD` อ่าน `AU`/`AS` → `BC` อ่าน `BD`/`AT`

หน้าสรุปยังตรวจสอบตัวเองได้: คอลัมน์ G (อัตราสัญญา) + H (ส่วนปรับ) = I (อัตราสุทธิ)

## 4. Sheet อัตราค่าขนส่ง

| ช่อง | เปลี่ยนอะไร |
|---|---|
| G H J | **ไม่เปลี่ยน** ยังเป็นช่องกรอกเหมือนเดิม ตอนนี้แถวรายเที่ยวมาอ่านไปใช้ |
| I ราคาน้ำมันเฉลี่ย | เปลี่ยนเป็น **แสดงอย่างเดียว** ไม่มีสูตรไหนเอาไปคิดเงินแล้ว จึงคงค่าเฉลี่ยธรรมดาของวันที่วิ่ง (`_exportDocumentFuelPriceByGroup`) ไว้ได้เต็มที่ |
| K L | เติม *(อ้างอิง)* ที่หัวคอลัมน์ แปลว่า "ถ้าคิดแบบเฉลี่ยจะได้เท่านี้" |
| M คีย์ | ไม่แตะ |
| N หมายเหตุ | เปลี่ยนข้อความเป็น "แสดงอย่างเดียว ไม่ได้ใช้คิดเงิน" |

## 5. ฝั่ง Django

ฟังก์ชันใหม่ใน `weightapp/views.py`

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `_exportDocumentFuelMatrix(trip_rows, month)` | คืนตารางราคา `{ชื่อเหมือง -> {วัน -> (ราคา, carried?)}}` พร้อม carry-forward |
| `_exportDocumentWriteFuelSheet(workbook, matrix)` | สร้าง sheet "น้ำมันรายวัน" เขียนข้อมูล + ทาสีเทาช่องที่ carry มา |
| `_exportDocumentWriteTripFormulas(worksheet, n_rows)` | เขียนสูตร AB–AH |
| `_exportDocumentPatchPayoutSheet(workbook)` | แก้ AU / BC / BD แถว 5–404 |

รายละเอียด `_exportDocumentFuelMatrix`

- บริษัทของแต่ละเหมือง มาจาก `BaseCompanyMapBaseCustomer.base_company_id` ของ `origin_map_id`
- carry forward ข้ามเดือนได้ — ต้องดึงราคาแถวล่าสุดก่อนวันที่ 1 ของเดือนมาด้วย
- วันที่ไม่มีราคาเลยจริง ๆ (ไม่เคยกรอกมาก่อน) → เว้นว่าง แล้วนับใส่ stats
- เหมืองที่ยังไม่ได้ผูกบริษัทในตาราง map → ทั้งแถวว่าง นับใส่ `stats['fuel_no_company']`

`_exportDocumentFuelPriceByGroup` คงไว้ ใช้เติมช่อง I อย่างเดียว ไม่เกี่ยวกับการคิดเงินอีกต่อไป

## สิ่งที่ยังใช้ได้เหมือนเดิม

- บัญชีแก้ G / H / J ในไฟล์ → หน้าสรุปคิดใหม่ทันที
- บัญชีแก้ราคาในตารางน้ำมันรายวัน → หน้าสรุปคิดใหม่ทันที
- วางทับช่วง A:K ในบันทึกรายเที่ยว (คอลัมน์ช่วยอยู่หลัง AA)
- dropdown เดิมทั้ง 16 ชุด (ผ่าน `xlsx_template.save_with_template_extensions`)
- ช่องตรวจทาน O5–O11 · sheet สรุปเหมือง · ปะหน้าจ่ายรถร่วม · oil — ไม่แตะ
- ปุ่ม "แก้ไขข้อมูลผ่าน Excel" — ไม่แตะ อ่านแค่คอลัมน์ A–K

## ข้อจำกัดที่ยอมรับ

**อัตราสุทธิที่แสดง × ตัน จะไม่เท่ายอดเงินเป๊ะ ต่างกันไม่กี่สตางค์**
เงินคิดทีละเที่ยวแล้วรวม ส่วนอัตราสุทธิเป็นตัวเลขย้อนกลับ (เงิน ÷ ตัน) ที่ปัด 2 ตำแหน่ง
ยอดเงินคือตัวจริง จะเขียนกำกับไว้บนหน้าสรุป

**เที่ยวที่หาชื่อเหมืองใน sheet น้ำมันรายวันไม่เจอ** จะได้ส่วนปรับ 0 เงียบ ๆ
แก้ด้วยการเพิ่มช่องนับในกล่องตรวจทานของบันทึกรายเที่ยว ซึ่งใช้ถึงแถว 11 แถว 12 ว่างอยู่

```
N12 = เที่ยวที่หาราคาน้ำมันไม่เจอ
O12 = =SUMPRODUCT(--($A$6:$A$3005<>""),--($AB$6:$AB$3005=""))
```

แล้วต่อเงื่อนไขเข้าไปในช่องเตือน O11 ก่อนกรณี "ปกติ"
`IF($O$12>0,"*** มีเที่ยวที่หาราคาน้ำมันไม่เจอ ***","ปกติ")`

## การพิสูจน์ว่าถูก

1. `Σ AH` ทุกเที่ยว = `Σ AU` ทุกกลุ่ม = ยอดรวมทั้งไฟล์
2. เทียบกับที่คำนวณใน Python: `Σ ตัน_i × (G + (น้ำมันวันนั้น_i − H) × J)` แยกตามกลุ่ม
3. เคสทีมไม่มีสัญญา → เงิน 0 เหมือนเดิม
4. เคสวันขาดราคา → carry forward ถูกวัน และช่องเป็นสีเทา
5. แก้ราคาในไฟล์แล้ว recalc → ยอดขยับตาม
6. re-upload ไฟล์ที่ไม่ได้แก้อะไร → ต้อง detect 0 changes (กันไม่ให้คอลัมน์ใหม่ไปกวนตัวอ่าน)
